What's Working Right Now

  • ✅
    Guest booking via chat — guests ask about availability, pricing, pavilions, guides, and make bookings through a WhatsApp-style conversation. Bookings are saved to a real cloud database.
  • ✅
    Staff scheduling — 21-on/7-off rotation for Nomsa and Thandiwe. Visual roster showing 4 weeks ahead with coverage indicators. Sundays auto-adjust based on guest bookings.
  • ✅
    Booking calendar — Gantt-style timeline showing bookings per pavilion. Export to Google Calendar or download .ics file.
  • ✅
    Rate management — Direct bookings vs Perfect Hideaways (20% commission). Conservation levy at R180/person/night auto-calculated.
  • ✅
    Email notifications — Real emails to you (guy@rumf.co.za) and Lisa-Jane (hamlin@mweb.co.za) when bookings come in. Guest confirmation emails sent automatically.
  • ✅
    Manager agent — Ask "what's occupancy this month?" or "show revenue" or "who's working today?" and get instant answers from live data.
  • ✅
    Leave management — Staff request leave via their agent, manager approves/denies via chat.
  • ✅
    Cloud database — All data persists in Cloudflare D1. Currently holding 7 guests, 7 bookings, 90+ chat messages, full audit trail.
  • ✅
    Agent learning log — Every interaction is logged with feedback (thumbs up/down) so the agent improves over time.

Why Agent-First

Traditional hospitality software makes everyone learn a new system — logins, menus, forms, training. Agent-first is different:

  • 💬
    Guests just message — like texting a friend. No app download, no account creation.
  • 📱
    Staff get SMS — no training, no app, just read and reply.
  • 🏠
    Managers ask questions — "how's occupancy?" instead of clicking through 5 screens.

This is the same architecture 2nth.ai uses for enterprise clients across finance, healthcare, manufacturing, and professional services. Luthuli Lodge is the conservation hospitality template — built to scale from 1 lodge to a group.
