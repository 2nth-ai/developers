Board Selection Guide

We match the right Pi to the job. More power than ESP32, less cost than industrial PCs.

Raspberry Pi 5
Cortex-A76 4×2.4GHz · 4/8GB
PCIe, dual 4K HDMI, USB3, GbE. Our primary board for edge AI, kiosks, and compute-heavy workloads. Runs TFLite & ONNX inference at usable framerates.
Edge AI · Kiosk · Gateway
Raspberry Pi 4B
Cortex-A72 4×1.8GHz · 2/4/8GB
Dual HDMI, USB3, GbE. Proven workhorse for automation, protocol gateways, and always-on services. Large ecosystem of HATs and accessories.
Automation · Gateway · Camera
Pi Zero 2 W
Cortex-A53 4×1GHz · 512MB
WiFi, BT, tiny form factor. Perfect for single-purpose embedded tasks — sensor collection, camera timelapse, lightweight monitoring. Runs headless on 5V/1A.
Sensor Hub · Camera · Embedded
Pico W
RP2040 dual M0+ 133MHz · 264KB
WiFi + BLE, 26 GPIO, ADC. MicroPython or C. Ultra-low power for battery-operated field sensors. No Linux overhead — bare metal or RTOS.
Microcontroller · Sensors · Pico
Pico 2 W
RP2350 dual M33 150MHz · 520KB
WiFi + BLE, dual-arch (ARM + RISC-V), more RAM, security features. Drop-in upgrade from Pico W for projects that need more headroom.
Pico · Advanced Sensors
Compute Module 5
Same SoC as Pi 5 · SO-DIMM
For custom carrier boards in commercial products. eMMC storage, PCIe, dual camera. When the solution needs to ship as a product, not a dev board.
Commercial Product · OEM
Solution Types We Build
Sensor Hub

Environmental Monitoring

Collect temperature, humidity, pressure, air quality, motion, and light data. Local SQLite logging + MQTT push to cloud dashboard. Runs 24/7 on a Pi Zero 2 W.

DHT22 / BME280 / PIR → Python → MQTT → 2nth.ai
Edge AI

On-Device ML Inference

Image classification, object detection, anomaly detection running locally on Pi 5. TensorFlow Lite or ONNX Runtime. No cloud latency, no data leaving the site.

PiCamera2 → TFLite / YOLO → alerts → 2nth.ai
Automation

Relay & Motor Control

Control relays, solenoids, servos, steppers, and pumps. Scheduled or event-driven. GPIO with hardware watchdog. Greenhouse, irrigation, access control, production lines.

GPIO → Relay Board → Flask API → systemd
Machine Vision

Camera & OCR

Security cameras with motion detection, timelapse photography, barcode/QR scanning, OCR document reading, and MJPEG/RTSP streaming. Pi Camera Module or USB cam.

PiCamera2 → OpenCV → detection → MQTT
Gateway

Protocol Bridge

Bridge BLE sensors, Zigbee devices, LoRa nodes, or Modbus RTU/TCP equipment to cloud via MQTT or REST. The Pi runs as an always-on edge gateway with local buffering.

BLE/Zigbee/Modbus → Pi → MQTT → Cloudflare
Kiosk

Touchscreen Display

Interactive dashboards, POS terminals, digital signage, visitor check-in. Pi 5 + official touchscreen or HDMI monitor. Chromium kiosk mode or PyQt6. Auto-start on boot.

Pi 5 → Chromium / PyQt6 → touchscreen → API
Robotics

Motor & IMU Control

DC motors via H-bridge, servo arrays, IMU (MPU6050/BNO055), ultrasonic/LIDAR distance, encoder feedback. Mobile robots, robotic arms, pan-tilt camera mounts.

L298N / PCA9685 → IMU → Python → control loop
Pico Microcontroller

MicroPython Field Devices

Pico W for ultra-low-power battery sensors, analog inputs, PWM outputs. No Linux boot time — instant on. WiFi + BLE connectivity. Pairs with Pi gateway for aggregation.

Pico W → MicroPython → WiFi → MQTT
Skills & Domain Knowledge

iot/raspberry-pi

Raspberry Pi system design: board selection (Pi 5/4B/Zero 2 W/Pico W), headless setup, GPIO programming (gpiozero, lgpio), I2C/SPI sensor drivers, camera integration (PiCamera2/libcamera), systemd service management, and deployment via SSH.

Raspberry Pi Linux IoT

iot/edge-inference

Edge AI on Raspberry Pi: TensorFlow Lite, ONNX Runtime, and OpenCV-based inference pipelines. Model optimisation (quantisation, pruning) for ARM. Object detection (YOLO/MobileNet), image classification, and anomaly detection running locally without cloud dependency.

Pi 5 Edge ML

iot/pi-automation

GPIO-driven automation: relay control, PWM dimming, servo positioning, stepper motor sequencing, solenoid actuation. Hardware watchdog timers, graceful shutdown on SIGTERM, and safe GPIO cleanup. Flask/FastAPI for local control APIs.

GPIO Automation

iot/pi-gateway

Protocol gateway design: BLE scanning (bleak), Zigbee coordination (zigpy), LoRa packet forwarding, Modbus RTU/TCP bridging. Local buffering with SQLite, MQTT forwarding to Cloudflare Workers, and device management via SSH.

Gateway Protocol Bridge

iot/pico-micropython

Pico W and Pico 2 W development with MicroPython: machine module (Pin, I2C, SPI, PWM, ADC, Timer, UART), WiFi provisioning, MQTT client, deep sleep power management, and deployment via mpremote. Pairs with Linux Pi as gateway.

Architecture — Pi in the 2nth.ai Stack
FIELD LAYER
  Pico W / ESP32 sensor nodes (battery, BLE/WiFi, MicroPython)
      │
      └── BLE / WiFi / LoRa

EDGE LAYER
  Raspberry Pi 4/5 (Linux, always-on, mains power)
      │
      ├── Sensor aggregation (BLE gateway, Modbus bridge)
      ├── Edge AI inference (TFLite, ONNX, OpenCV)
      ├── Local automation (GPIO, relays, motors)
      ├── Local storage (SQLite, CSV buffer)
      └── Kiosk / dashboard (Chromium, PyQt6)
      │
      └── MQTT (TLS) / REST API

CLOUD LAYER
  Cloudflare Workers (ingestion, API)
      │
      ├── D1 (time-series, device registry)
      ├── KV (latest values, config, OTA manifests)
      ├── R2 (firmware binaries, images, backups)
      └── 2nth.ai (AI analysis, alerts, skills)
