Mode 2 · Training Tab

The full portal, pinned as a tab.

IT admins pin the Calypso Training Hub as a tab in each functional team — "📌 Calypso Training" appears next to Posts and Files. Each user sees their own progress, role track, and upcoming assessments. Authentication is Azure AD SSO — no separate login.

What each user sees in the Training Tab
01
Role dashboard
Personalised view based on their Calypso role track — Front Office, Middle Office, Operations, or Tech. Module progress rings and next-up recommendations.
02
Module catalog
All 6 Calypso modules available inline — Trade Capture, Risk, Collateral, Treasury, Settlement, Regulatory. Tap to open a module without leaving Teams.
03
Assessment hub
Due assessments, past scores, certificates. Manager view available to team leads to see team-wide completion rates per country/role.
04
Jurisdiction notices
SARB, CBN, CBK regulatory updates surfaced as banners — e.g., new FSCA reporting format, JIBAR transition timeline, CBN FX circular updates.
05
AI chat panel
The CalypsoBot assistant embedded directly in the tab sidebar — same AI as the channel bot, with full module context pre-loaded from the tab's active module.
SSO — Zero login friction
Azure Active Directory token is passed to the 2nth.ai backend via the Teams SSO flow. The platform maps the user's AAD object ID to their SBG Calypso role assignment — no separate Training Hub login needed across all 20 countries.
Manager view for team leads
Calypso team leads (e.g., Head of JHB Treasury Desk) see an aggregated view of their team's training completion rates, assessment scores, and outstanding modules. Exportable to Excel for HR reporting.
Content stays current
The tab is a web view into the live Training Hub — when Andile pushes a Calypso knowledge base update or a new SARB circular, every Teams tab across all 20 SBG countries reflects the change immediately. No app store update needed.
Mobile-ready
Teams Mobile (iOS/Android) renders the Training Hub and CalypsoBot. Operations staff on the floor in Lagos or Nairobi can ask settlement questions from their phone mid-workflow.

IT deployment

Four steps to deploy across SBG Africa.

Andile's implementation team handles the technical deployment. IT admins approve and push the app via the Microsoft Teams Admin Centre — no code deployment needed from the bank's side.

🏗️
Step 1 · Andile
App manifest & webhook provisioning
Andile configures the Teams app manifest with Standard Bank's tenant ID, bot endpoint pointing to the 2nth.ai Cloudflare Worker, and tab URL for the Training Hub. The CalypsoBot webhook is registered in Azure Bot Framework and scoped to SBG's AAD tenant.
manifest.json → { "id": "sbg-calypso-training", "botId": "...", "tabUrl": "https://training.calypso.2nth.ai/teams-tab" }
🔐
Step 2 · SBG IT · AAD
Azure AD app registration & SSO consent
SBG IT registers the 2nth.ai application in Azure Active Directory. Grant admin consent for User.Read and profile scopes. User's AAD object ID maps to their Calypso role in the Training Hub — no additional provisioning per user.
az ad app permission add --id {APP_ID} --api {GRAPH_API} --api-permissions e1fe6dd8-ba31... (User.Read)
🏢
Step 3 · SBG IT · Teams Admin
Publish to SBG app store & assign policies
Upload the app package to Microsoft Teams Admin Centre → Manage Apps. Create app setup policies to auto-pin the Training Hub tab in the Capital Markets team and pre-install CalypsoBot for all users in the Calypso security group. Rollout can be phased by country: South Africa first, then Kenya and Nigeria.
Teams Admin Centre → Setup Policies → "SBG Calypso Users" → Add pinned apps → CalypsoBot + Calypso Training
🗄️
Step 4 · Andile · Knowledge base
Knowledge base load & jurisdictional tuning
Andile ingests Standard Bank's Calypso configuration documentation, SARB/CBN/CBK regulatory circulars, and internal training materials into Cloudflare Vectorize. Regional tuning maps AAD country attributes to jurisdiction-specific RAG namespaces — a Nairobi user automatically gets CBK context; Johannesburg gets SARB.
wrangler vectorize insert --index calypso-sbg-training --namespace ZA_SARB documents/sarb/*.pdf
Architecture · Teams integration

How a Teams message becomes a Calypso answer.

Message → Answer pipeline · Teams + 2nth.ai
1
Teams Bot Framework — Incoming activity
User @mentions CalypsoBot in a channel or sends a message in the bot's 1:1 chat. Microsoft Teams sends an Activity JSON payload (message text, user AAD ID, channel context) to the registered bot endpoint.
POST https://calypso-bot.2nth.ai/api/messages ← Teams Bot Framework webhook
2
Cloudflare Worker — Auth & session enrichment
The Worker validates the Teams bot JWT, resolves the user's AAD object ID against the SBG user store in D1, and retrieves their region (ZA/KE/NG), Calypso role track, and active module from KV. Context is bundled for downstream AI prompt construction.
D1 SELECT role, region, module FROM users WHERE aad_id = ? · KV GET session:{aad_id}
3
Workers AI — Intent classification
Llama 3.1 8B classifies the query (trade capture / settlement / risk / regulatory / config) and selects the Vectorize namespace: ZA_SARB, KE_CBK, NG_CBN, or GLOBAL_CALYPSO.
Workers AI · @cf/meta/llama-3.1-8b-instruct · intent + namespace → ~80ms
4
Vectorize RAG — Knowledge retrieval
Semantic search across Calypso documentation, SBG config notes, and regulatory circulars in the user's jurisdiction namespace. Top-8 chunks retrieved and ranked by relevance score.
Vectorize · {namespace} · text-embedding-3-small · top-k=8 · threshold=0.70
5
Claude — Answer generation
Claude Sonnet 4.6 generates a structured response with Calypso navigation paths, regulatory context, and jurisdiction-specific notes. Output is structured as an Adaptive Card JSON schema for rich rendering in Teams.
2nth.ai AI Gateway → claude-sonnet-4-6 · Adaptive Card JSON output schema
6
Teams Bot Framework — Adaptive Card reply
The Cloudflare Worker posts the Adaptive Card back to Teams via the Bot Framework reply URL. The card renders natively in Teams with step-by-step sections, regulatory tags, and action buttons (Open Module, Full Guide, Ask follow-up) — all without leaving the channel.
POST replyToActivityUrl · Content-Type: application/json · Adaptive Card v1.5
