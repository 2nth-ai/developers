Skills & Domain Knowledge

iot/esp32-development

ESP32 firmware development: Arduino and ESP-IDF frameworks, FreeRTOS task management, peripheral drivers (I2C, SPI, UART, ADC), BLE GATT services, WiFi provisioning, OTA updates, deep sleep power management, and secure boot.

ESP32 Firmware

iot/mqtt-telemetry

MQTT-based IoT telemetry: broker architecture (Mosquitto, HiveMQ, Cloudflare Pub/Sub), topic design, QoS levels, retained messages, last will, TLS/mTLS, and data pipeline from device to Cloudflare Workers to D1/KV storage.

MQTT Cloud

iot/edge-ai

Machine learning at the edge: TensorFlow Lite Micro on ESP32-S3, on-device anomaly detection, vibration pattern classification, predictive maintenance models, and the trade-offs between edge inference and cloud processing.

ESP32-S3 Edge ML

iot/industrial-monitoring

Industrial IoT deployments: power monitoring (CT clamps, 3-phase), vibration analysis (FFT, bearing defect frequencies), temperature mapping, environmental compliance, and integration with existing SCADA/PLC systems via Modbus RS485.
