Build partner track

The development build track is for engineers who want to build directly on the 2nth.ai platform — shipping skills, integrations, and edge-native AI features.

1

Set up GitHub & Cloudflare

Create a GitHub account (or use your existing one) and a Cloudflare account. Both are free to start. Your account manager will add you to the 2nth.ai GitHub org and Cloudflare team once setup is confirmed.

2

Install Wrangler CLI

Install Node.js (≥18) and run npm install -g wrangler. Authenticate with wrangler login. This is the primary deployment tool for all 2nth.ai edge projects.

3

Clone the dev environment

Start with the 2nth-beta repository — the main platform codebase. Run npm run dev to spin up a local environment with all bindings (D1, KV, Workers AI) wired up.

4

Build your first skill

Pick a domain (tech, biz, fin, etc.), create your skill directory, and write your SKILL.md. Submit a PR targeting dev and the team will review within 48 hours.

5

Graduate to platform builds

Once you've shipped a skill, you can move into platform feature work — Workers, edge functions, D1 integrations, and AI agent logic. Full platform access with token budget included.

How the build partnership works

James
Builds skills, integrations, and edge-native features on the 2nth.ai platform. Contributes clean, maintainable TypeScript targeting the Cloudflare Workers runtime. Reviews go through the standard dev → beta → main lifecycle.
2nth.ai
Provides platform access, Workers AI token budget, D1 and KV bindings, code review, and the skills catalog infrastructure. Routes AI inference through the 2nth AI Gateway (Llama 3.1 8B → Claude Sonnet 4.6).
Revenue
Community contributors earn a revenue share (default 5%, negotiable) on skills with paying tier usage. Skills must be active-status and pass the CI validation pipeline before share accrues.
Stack
TypeScript throughout. Cloudflare Pages + Workers for compute. D1 (SQLite) for persistence. KV for sessions and caching. Vectorize for RAG. R2 for storage. Workers AI for edge inference. No Docker, no VMs.
