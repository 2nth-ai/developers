Environment indicator

Every non-production deployment shows a coloured banner so users always know which environment they're in. Drop env-banner.js into any page — it detects the hostname and renders the correct ribbon automatically.

Dev preview.2nth-beta.pages.dev
Not for clients
Beta 2nth-beta.pages.dev
UAT — may change
Production 2nth.ai
Live

Install it on any page:

<!-- Drop before </body> on any 2nth subdomain -->
<script src="https://2nth-beta.pages.dev/env-banner.js"></script>

It reads window.location.hostname and injects a fixed top ribbon. On *.2nth.ai production domains it renders nothing — no visual noise for real users.

Day-to-day git flow

# Start a new feature
$ git checkout dev && git pull origin dev
$ git checkout -b feature/my-feature

# Work, commit, push
$ git commit -m "feat: describe the change"
$ git push origin feature/my-feature

# PR: feature → dev (no review required)
$ gh pr create --base dev --title "feat: my feature"

# PR: dev → beta (1 approval required)
$ gh pr create --base beta --title "promote: dev → beta vX.Y"

# PR: beta → main (UAT + 1 approval)
$ gh pr create --base main --title "release: v1.x — what changed"

Rollback

Force push is disabled on all protected branches. To roll back, create a revert commit — this keeps history clean and triggers the normal deploy pipeline.

# Revert the last production commit
$ git revert HEAD --no-edit
$ git push origin main

# Revert a specific commit by hash
$ git revert abc1234 --no-edit && git push origin main

# Cloudflare Pages also keeps every deploy — you can instant-rollback
# from the CF dashboard without touching git at all
