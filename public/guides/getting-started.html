1. How it all fits together

# The 2nth.ai stack

You (partner)
  → Write code + skills using Claude Code (AI programming assistant)
  → Push to GitHub (version control)
  → Deploy to Cloudflare Pages (hosting — free tier works)
  → Skills land in the 2nth.ai skill tree (300+ AI skills)
  → Agents use your skills to serve customers
  → You earn revenue share on every execution
You need 3 accounts (all free):
1. GitHub — for code
2. Cloudflare — for hosting
3. Claude Code — for AI programming (Anthropic account)

2. Create your accounts

1

GitHub

Go to github.com/join. Create a free account. You'll use this to store your code and contribute skills.

2

Cloudflare

Go to Cloudflare sign-up. The free tier gives you: Pages (hosting), Workers (serverless), D1 (database), KV (key-value store). That's the full 2nth.ai stack.

3

Claude Code (Anthropic)

Go to claude.ai and create an account. Claude Code is the AI programming assistant you'll use to write code, create skills, and build your projects. It runs in your terminal.

3. Windows setup for Claude Code

Windows Claude Code runs in the terminal. On Windows, you need a few tools first.

1

Install Node.js

Download from nodejs.org — get the LTS version (not Current). Run the installer, accept all defaults.

Verify it worked — open Command Prompt or PowerShell and run:

node --version    # Should show v20.x or v22.x
npm --version     # Should show 10.x+
2

Install Git

Download from git-scm.com. Run the installer — accept all defaults. This also installs Git Bash which gives you a Unix-like terminal on Windows.

git --version     # Should show git version 2.x
3

Install VS Code (recommended)

Download from code.visualstudio.com. This is your code editor. Install the Claude Code extension from the VS Code marketplace.

4

Install Claude Code CLI

Open your terminal (PowerShell, Command Prompt, or Git Bash) and run:

npm install -g @anthropic-ai/claude-code

Once installed, authenticate:

claude auth login

This opens your browser to sign in with your Anthropic account.

5

Install Wrangler (Cloudflare CLI)

npm install -g wrangler

Then authenticate with your Cloudflare account:

wrangler login
6

Configure Git

git config --global user.name "Your Name"
git config --global user.email "you@company.com"
You're ready! You now have: Node.js, Git, VS Code, Claude Code, and Wrangler. Open a terminal in any folder and type claude to start your AI programming assistant.

4. Mac setup (quick)

Mac Mac already has a terminal. You just need the tools.

# Install Homebrew (if you don't have it)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install everything
brew install node git
npm install -g @anthropic-ai/claude-code wrangler

# Authenticate
claude auth login
wrangler login

# Configure Git
git config --global user.name "Your Name"
git config --global user.email "you@company.com"

5. GitHub — fork, branch, and contribute

Fork the skills repo

Go to github.com/2nth-ai/skills and click Fork (top right). This creates your own copy of the skill tree.

Clone your fork

git clone https://github.com/YOUR-USERNAME/skills.git
cd skills

Create a branch for your work

# Always branch from dev, not main
git checkout dev
git checkout -b partner/my-new-skill

Make your changes, commit, push

# After editing files...
git add .
git commit -m "feat: add my-new-skill"
git push origin partner/my-new-skill

Create a Pull Request

Go to your fork on GitHub → click Compare & pull request → target the dev branch on 2nth-ai/skills. The 2nth team reviews within 5 business days.

Important: Never push directly to main. The main branch is protected and requires a PR with review. Always work on dev or a feature branch.

6. Cloudflare — deploy your first site

Create a Pages project

# Create a new project folder
mkdir my-partner-site
cd my-partner-site
mkdir public

# Create a simple index.html
echo '<h1>Hello from my partner site</h1>' > public/index.html

# Deploy to Cloudflare Pages
npx wrangler pages deploy public --project-name=my-partner-site

Wrangler will create the project and deploy it. You'll get a URL like my-partner-site.pages.dev. That's your site — live on the internet.

Add a custom domain (optional)

In the Cloudflare dashboard → Workers & Pages → your project → Custom domains → add your domain.

Add serverless functions

# Create a functions directory
mkdir functions/api

# Create an API endpoint
cat > functions/api/hello.js << 'EOF'
export async function onRequestGet() {
  return Response.json({ message: 'Hello from my API!' });
}
EOF

# Redeploy
npx wrangler pages deploy public --project-name=my-partner-site

Your API is now at my-partner-site.pages.dev/api/hello.

7. Your first partner project

The fastest way to build a partner project is with Claude Code. Open your project folder and start a conversation:

cd my-partner-site
claude

# Now you're in Claude Code. Tell it what to build:
> Build me a landing page for my consulting practice.
  Use the 2nth.ai design system — Bebas Neue for headings,
  Barlow for body, JetBrains Mono for code. Light mode.
  Add an enquiry form that sends to my email via Resend.

Claude Code will create the HTML, CSS, and serverless functions for you. Review what it writes, approve the changes, and deploy:

npx wrangler pages deploy public --project-name=my-partner-site
Pro tip: Create a CLAUDE.md file in your project root. This tells Claude Code about your project — what it does, what stack you use, what patterns to follow. Claude reads it every time you start a session.

Example CLAUDE.md

# My Partner Project

This is a partner site for [Company Name] on the 2nth.ai platform.

## Stack
- Cloudflare Pages (static + Functions)
- No frameworks — vanilla HTML, CSS, JS
- Resend for transactional email
- 2nth.ai design system (Bebas Neue, Barlow, JetBrains Mono)

## Deploy
npm run deploy  # or: npx wrangler pages deploy public

## Important
- Light mode by default
- Never hardcode API keys — use wrangler secrets
- All pages must work without JavaScript (progressive enhancement)

8. Contributing a skill

A skill is a SKILL.md file that teaches AI agents how to do something. Every skill follows the SKILL_FORMAT.md spec.

Create your skill

# In your fork of 2nth-ai/skills
mkdir -p biz/my-skill
cat > biz/my-skill/SKILL.md << 'EOF'
---
name: biz/my-skill
description: |
  What this skill does and when to use it.
  (1) use case one,
  (2) use case two,
  (3) use case three.
license: MIT
metadata:
  author: your-name
  version: "1.0.0"
  categories: "Business, Your Domain"
---

# My Skill

One paragraph: what it is and why it matters.

## Authentication
How to authenticate (env vars, never hardcode).

## Core patterns
The 3-5 most important things.

## Common Gotchas
- Gotcha 1
- Gotcha 2
- Gotcha 3
EOF

Test it locally

# Build the catalog to check your skill renders
node catalog/build.js

Submit it

git add biz/my-skill/
git commit -m "feat: add biz/my-skill"
git push origin partner/my-new-skill
# Then create a PR on GitHub targeting dev branch
